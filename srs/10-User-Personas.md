# User Personas

---

# 1. Overview

User Personas are fictional representations of the primary users of the SmartDoc website. They help define user needs, behaviors, goals, and challenges, ensuring that the website is designed with real users in mind.

The personas below are based on the target audience of SmartDoc.

# Common User Needs

Most SmartDoc users expect the following:

- Accurate service information.
- Simple and understandable content.
- Fast website performance.
- Mobile responsiveness.
- Professional appearance.
- Easy navigation.
- Reliable communication through WhatsApp.

---

# Design Considerations

Based on the user personas, the website should:

- Follow a mobile-first approach.
- Use simple and easy-to-read language.
- Maintain a clean and uncluttered layout.
- Keep important actions easily accessible.
- Provide a consistent user experience across all devices.
