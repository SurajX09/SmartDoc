# User Roles

---

# 1. Overview

This document defines the different user roles within the SmartDoc website and the permissions associated with each role.

The current version of SmartDoc is an informational website. Therefore, user interaction is limited to browsing content and contacting SmartDoc through WhatsApp.

---

# 2. User Roles

The SmartDoc website currently supports the following user roles:

- Visitor
- Administrator

---

# 3. Visitor

A Visitor is any person who accesses the SmartDoc website using a supported web browser.

Visitors are not required to register or log in before using the website.

### Responsibilities

- Browse website pages.
- Read service information.
- Understand required documents.
- Read Frequently Asked Questions (FAQ).
- Contact SmartDoc through WhatsApp.

### Permissions

Visitors are allowed to:

- Access all public pages.
- View service details.
- View contact information.
- Use WhatsApp call-to-action buttons.
- Navigate the website freely.

### Restrictions

Visitors cannot:

- Register an account.
- Log in.
- Upload documents.
- Modify website content.
- Access administrative features.

---

# 4. Administrator

The Administrator is responsible for maintaining the SmartDoc website and ensuring that the published information remains accurate and up to date.

### Responsibilities

- Manage website content.
- Update service information.
- Maintain FAQ content.
- Verify contact information.
- Review website quality before updates.

### Permissions

The Administrator is authorized to:

- Edit website content.
- Publish updates.
- Correct information.
- Maintain service listings.
- Ensure overall website accuracy.

### Restrictions

The Administrator should:

- Publish only verified information.
- Maintain consistent formatting.
- Ensure professional language.
- Avoid publishing incomplete or misleading content.

---

# 5. Role Comparison

| Feature | Visitor | Administrator |
|----------|:-------:|:-------------:|
| View Website | ✅ | ✅ |
| View Services | ✅ | ✅ |
| Read FAQs | ✅ | ✅ |
| Contact via WhatsApp | ✅ | ✅ |
| Edit Content | ❌ | ✅ |
| Publish Updates | ❌ | ✅ |
| Manage Website | ❌ | ✅ |

---

# 6. Access Control

The current version of SmartDoc does not require user authentication.

All website pages are publicly accessible to visitors.

Administrative activities are managed separately and are outside the scope of the public website.
