# Assumptions and Constraints

---

# 1. Overview

This document defines the assumptions and constraints considered during the planning and development of the SmartDoc website.

Assumptions represent conditions believed to be true during the project lifecycle, while constraints define the limitations within which the project must be completed.

Clearly identifying these factors helps reduce project risks and ensures realistic planning.

---

# 2. Assumptions

The following assumptions have been made for the current version of SmartDoc.

### Business Assumptions

- The information provided on the website is accurate and up to date.
- Users will contact SmartDoc through WhatsApp for further assistance.
- Services offered by SmartDoc will remain available unless updated by the business owner.

---

### User Assumptions

- Users have access to the internet.
- Users are familiar with basic website navigation.
- Users have WhatsApp installed on their device.
- Users are responsible for providing correct information during communication.

---

### Technical Assumptions

- Users will access the website using a modern web browser.
- JavaScript is enabled in the user's browser.
- Internet connectivity is available while using the website.
- The website will be hosted on a reliable hosting platform.

---

# 3. Project Constraints

The following constraints apply to the current version of SmartDoc.

---

## Functional Constraints

- The website is informational only.
- Users cannot create accounts.
- Users cannot upload documents.
- Users cannot make online payments.
- Users cannot submit applications through the website.

---

## Technical Constraints

- The website will be developed using React and Tailwind CSS.
- The project follows a mobile-first responsive design approach.
- The website must function correctly on modern browsers.

---

## Business Constraints

- Communication will take place through WhatsApp.
- Service information must remain simple and easy to understand.
- The website should maintain a professional and trustworthy appearance.

---

# 4. Dependencies

The successful operation of the website depends on:

- Stable internet connectivity.
- WhatsApp availability.
- Hosting availability.
- Domain availability.
- Updated service information.

---

# 5. Risks

Possible risks include:

- Incorrect or outdated service information.
- WhatsApp service interruptions.
- Browser compatibility issues.
- Poor internet connectivity for users.
- Delays in updating website content.

---

# 6. Risk Mitigation

To reduce project risks:

- Regularly review website content.
- Test the website across multiple browsers.
- Optimize website performance.
- Keep contact information updated.
- Perform routine maintenance after deployment.
