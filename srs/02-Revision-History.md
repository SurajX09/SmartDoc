## Versioning Guidelines

The following versioning convention will be used throughout the project.

| Version Type | Description |
|--------------|-------------|
| Major (1.0, 2.0) | Significant changes such as new modules, major redesigns, or architecture updates. |
| Minor (1.1, 1.2) | Addition of new sections, requirement updates, or content improvements. |
| Patch (1.0.1, 1.0.2) | Typographical corrections, formatting fixes, or minor documentation changes. |
